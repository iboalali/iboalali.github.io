_Icon Recomposer_ does **not** use cookies and does **not** collect any personal information. No accounts, no tracking across sites, no advertising. Any artwork or project file you open is processed locally in your browser and is never uploaded to a server; files leave your device only when you choose to export or save them.

{% heading "Analytics", "analytics" %}

Anonymous usage analytics are collected via [TelemetryDeck](https://telemetrydeck.com) so I can see how many people use the app. **No personal information** (PII) is sent. TelemetryDeck does not use cookies or browser fingerprinting; visitors are identified by a hash derived from IP address, user agent, app ID, and a daily-rotating salt. The hash cannot be reversed and changes every day.

See [TelemetryDeck's privacy FAQ](https://telemetrydeck.com/docs/guides/privacy-faq/) for full details.

{% heading "Hosting", "hosting" %}

Icon Recomposer is hosted on GitHub Pages. GitHub may log standard request metadata (such as IP address and user agent) for security and operational purposes. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.
